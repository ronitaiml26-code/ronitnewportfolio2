# Ronit Kumar Singh — Futuristic AI & Tech Portfolio

A modern, futuristic, highly interactive personal portfolio website for **Ronit Kumar Singh**, a first-year B.Tech student at **JECRC University**.

Designed with a cyber-dark AI & tech builder aesthetic, featuring **Neon Blue** (`#00F0FF`) and **Neon Yellow** (`#FFE600`) visual accents, and a subtle **Green Blurred Speed-Text Background** (`#00FF66`).

---

## ⚡ Key Highlights & Features

1. **Futuristic Theme & Visual Identity**:
   - Deep dark cyber glassmorphism surfaces (`rgba(9, 14, 28, 0.72)`).
   - Primary Accent: Neon Blue (`#00F0FF`) with glowing outer aura.
   - Secondary Accent: Neon Yellow (`#FFE600`) for energetic highlights and milestones.
   - Speed-Text Matrix Canvas: Subtle, heavily blurred falling code streams in cyber-green (`#00FF66`) running unobtrusively in the background without affecting text contrast.
   - Typography: Orbitron (Display), Syne (Headings), Plus Jakarta Sans (Body), and JetBrains Mono (Badges & Code).

2. **Interactive Elements**:
   - **Hero AI Neural Constellation**: Dynamic canvas rendering node particles with glowing filaments that react to mouse position.
   - **Terminal HUD**: Typing animation cycling through tech commands and scripts.
   - **3D Card Micro-Tilt**: Desktop pointer tracking that tilts cards subtly in 3D perspective.
   - **Scroll Reveal Animations**: Smooth section entry transitions powered by `IntersectionObserver`.
   - **One-Click Quick Copy**: Instant copy for Email (`ronit.aiml@gmail.com`) and Phone (`7479767400`) with interactive cyber toast alerts.

3. **Complete Section Layout**:
   - **Header**: Sticky glassmorphic navigation with active scroll spy and responsive mobile drawer.
   - **Home / Hero**: Hook line, intro, dual CTA buttons ("Explore My Skills" & "Connect With Me"), and neural visual.
   - **About Me ("Who Am I?")**: Human story, personal details (DOB: 09/12/2007, Bokaro, Jharkhand, JECRC University), animated "My Journey" node line (`First Year → Learn → Build → Experiment → Improve → Grow`), hobbies tags, and quote.
   - **Skills ("What I Can Do")**: 6 glowing cards: AI Chatbot Development, Resume Making, Prompt Engineering, C Programming, Python, Java.
   - **Extra Skills ("Beyond Coding")**: Highlighting **20K+** Instagram followers milestone, **5+** accounts helped grow to 5K+, and social growth competencies.
   - **Projects ("What I'm Building")**: Portfolio build, AI Chatbot (Coming Soon), and Web App (Coming Soon) with honest status tags.
   - **Roadmap ("Currently Learning & Coming Next")**: Dual column layout ("Currently Exploring" vs "Coming Next") and continuous learning pipeline.
   - **Contact ("Let's Connect")**: Mailto CTA action (`mailto:ronit.aiml@gmail.com?subject=Connect%20with%20Ronit`), direct phone (`7479767400`), location, and social channel links.
   - **Footer**: Futuristic minimal footer with status indicator and back-to-top button.

## 🚀 How to Run Locally

### Option 1: One-Click Launcher (Windows)
Double-click `start_preview.bat` in the project folder to open the website directly in your default browser.

### Option 2: Open Directly
Double-click `index.html` or right-click `index.html` → **Open with** → Chrome / Edge / Firefox.

## 🌐 Free Deployment Options

This website is built with zero dependencies, making deployment effortless:

- **GitHub Pages**:
  1. Create a repository on GitHub (e.g. `portfolio`).
  2. Push these files to the `main` branch.
  3. Go to **Settings** → **Pages** → Source: **Deploy from branch (main)**.
  4. Your website is live!

- **Vercel / Netlify**:
  - Drag and drop this folder directly into the [Vercel](https://vercel.com) or [Netlify](https://netlify.com) dashboard for instant global CDN deployment.
